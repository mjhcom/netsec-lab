# netsec-lab

网络安全学习实验记录（大一上）。

## 内容
- `analyzer.py`：日志分析函数（正则提取 IP、字典统计、降序排序、失败登录统计）
- `main.py`：主程序，命令行传参调用分析函数
- `Windows Server AD 域控搭建实验总结.md`：AD DS 安装、提升域控、OU/用户管理

## 环境
- Python 3.14（venv）
- Windows Server 2022
- Ubuntu 24.04

## 学习进度
- 网络：VLAN、单臂路由、静态路由、ACL、NAT、端口安全
- Linux：Vim、grep、awk、sed、chmod、chattr、UFW、巡检脚本
- Python：正则、文件读写、异常处理、模块化、subprocess 自动封禁
